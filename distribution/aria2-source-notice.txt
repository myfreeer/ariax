Ariax source distribution: extracted aria2 compatibility material

Upstream: https://github.com/aria2/aria2
Revision: 9e7273583f83e881e3ec067b523ba88724088d2f

Scope: upstream material extracted into generated/aria2_options.json,
generated/aria2_rpc.json and generated/aria2_compat.json retains
GPL-2.0-or-later terms and the applicable original notices reproduced below.
The full GPL version 2 text is distribution/licenses/aria2-GPL-2.0.txt.
The project MIT license does not replace these upstream terms.

Ariax modifications (2026): extract constructor expressions, interface names,
conditions and manual option directives; normalize their presentation as JSON;
add source positions, counts, comparisons and project compatibility status.
The extraction source is tools/ariax-xtask/src/inventory.rs and
 tools/ariax-xtask/src/config_contracts.rs; compat/aria2-reference.pin records
 the input revision. All generated artifacts are distributed in source form.
Ariax-owned additions may be used under MIT and are distributed compatibly
with the upstream GPL material in these combined source artifacts.

The CLI does not compile or embed these JSON inventories or link aria2.
They are excluded from the binary package manifests. Binary compatibility
with aria2 interfaces does not by itself make aria2 source part of the CLI.

Original notices follow. The OpenSSL exception is reproduced as upstream
wrote it; Ariax does not rely on that exception to link aria2 code.
