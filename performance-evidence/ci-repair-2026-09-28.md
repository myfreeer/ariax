## Changes

The full-feature CLI test imports shared status and identity types from
`ariax-core`, following the public Rust contract. No engine re-export or
compatibility alias is introduced.

Full-feature Clippy also exposed oversized transfer variants in mixed admission
staging, a complex checkpoint type, and test-only code compiled by the custom
benchmark harness. Transfer records now use owned boxes, and a type alias names
the checkpoint together with its retained byte permit. The peer-framing tests
live in the normal integration-test target and include the unchanged shared
parser. Their success and rejection assertions are preserved.

The separate BitTorrent fuzz target uses one conditional chain in place of
nested conditionals, preserving its identity and tracker-removal assertions.
The native security fixture converts libtorrent's typed alert mask through its
unsigned representation. Allowed web-seed cases require a payload response
before declaring completion and inspect the output after shutdown drains native
disk writes.

The resumed runtime checks exposed two further defects. New BitTorrent output
roots inherited the process umask and could fail their own protection check;
the builder now creates missing directories privately without modifying existing
roots. The CLI regression checks private creation for all three torrent versions
and rejects a shared output root without changing its permissions or writing
payload files.

The same CLI parity test now compares typed options with extended RPC's full
map and checks the aria2/strict projection separately. The latter intentionally
omits the two engine checkpoint-bound options. The compatibility implementation
and its wire behavior are unchanged.

The checkpoint-deadline fixture waits for the scheduler cancellation barrier to
clear as well as native removal before resuming. A paused snapshot alone could
race that barrier and prevent the test from reaching its expired-shutdown
scenario. The safe-resume and dirty-generation assertions are preserved.

The combined HTTP/stdio fixture intermittently timed out on WSL1 with the
earlier helper's multiple small TCP writes. The helper now enables `TCP_NODELAY`
and writes the complete HTTP header and body in one buffer. Its existing
three-second read and write deadlines are unchanged. Response errors identify
the stdio framing, EOF policy and child process.

Exhausted web seeds were also charged against libtorrent's default connection
limit, so a redirect chain stopped after three requests. Native patch level 3
excludes seeds with no remaining files from that count. The endpoint fixture
requires a payload after 20 redirects and the native SSRF error on the next hop,
using the default connection limit.

These changes preserve aria2 RPC responses, feature bundles, native ABI,
persistence formats, admission publication and checkpoint reservation lifetimes.
Native installations must be rebuilt for the new source and patch digests.
